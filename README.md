# Arduino 距離遊戲

這是一個使用 Arduino 和超音波感測器（HC-SR04）製作的互動遊戲。玩家需要將物體放在感測器前方特定距離處（預設 20 公分），當距離正確時，LED 會亮起並播放勝利音效。

## 硬體需求

- Arduino 開發板（如 Arduino UNO）
- HC-SR04 超音波距離感測器
- LED（任何顏色）
- 無源蜂鳴器
- 220Ω 電阻（用於 LED）
- 麵包板
- 杜邦線若干

## 接線說明

### 超音波感測器 (HC-SR04)
- VCC → Arduino 5V
- GND → Arduino GND
- TRIG → Arduino D12
- ECHO → Arduino D11

### LED
- 正極（長腳）→ Arduino D8
- 負極（短腳）→ 220Ω 電阻 → Arduino GND

### 蜂鳴器
- 正極 (+) → Arduino D9
- 負極 (-) → Arduino GND

## 運作原理

1. 程式會持續測量感測器前方物體的距離
2. 目標距離設定為 20 公分，允許誤差範圍 ±2 公分
3. 當物體位於正確距離時：
   - LED 會亮起
   - 蜂鳴器播放勝利音效
   - Serial Monitor 顯示成功訊息
4. 當物體不在正確距離時：
   - LED 保持熄滅
   - 蜂鳴器播放錯誤提示音
   - Serial Monitor 顯示「太近了」或「太遠了」的提示

## 使用方法

1. 將程式碼上傳到 Arduino 開發板
2. 開啟 Serial Monitor（鮑率設為 9600）
3. 在感測器前方緩慢移動物體
4. 觀察 LED 和聆聽蜂鳴器的反饋
5. 根據 Serial Monitor 的提示調整物體位置

## 參數調整

您可以修改以下參數來自訂遊戲：
- `TARGET_DISTANCE`：更改目標距離（預設 20 公分）
- `TOLERANCE`：調整允許的誤差範圍（預設 ±2 公分）

## 除錯提示

- 如果感測器無法正確讀取距離，請檢查：
  1. 接線是否正確
  2. 感測器前方是否有障礙物
  3. 物體表面是否太過光滑或透明
